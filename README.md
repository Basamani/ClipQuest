🎬 ClipQuest

Every video has the answer.

ClipQuest is an automated video and audio semantic chaptering and deep-search system. It helps users organize long media files into meaningful chapters, search for specific information, and access study materials.

🚀 Features

- Upload video and audio files.
- Automatic speech transcription.
- Automatic chapter generation.
- Semantic search across media content.
- Search using natural-language questions.
- Timestamp-based search results.
- Multiple language options.
- Study tools: summaries, notes, quizzes and flashcards.
- Media library for managing saved files.

🌐 Language Support

- English
- Kannada
- Hindi
- Telugu
- Tamil
- Other language options

🛠️ Technologies Used

- Python
- Streamlit

⚙️ Installation

1. Clone the repository

git clone https://github.com/Basamani/ClipQuest.git

2. Open the project

cd ClipQuest

3. Create a virtual environment

python -m venv venv

4. Activate the environment

Windows:

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Run the application

streamlit run app.py

🔍 How It Works

1. Upload a video or audio file.
2. Extract speech using transcription.
3. Generate meaningful chapters.
4. Convert chapter content into searchable representations.
5. Ask questions to find relevant media segments.
6. Explore summaries, notes, quizzes and flashcards.
